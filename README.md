# ECHONA 2026 reconstruction

Faithful static reconstruction of https://anandice.ac.in/echona2026/ using its original public HTML, scripts and media.

Run `npm run dev` and open http://localhost:4173.

Pages: index.html, crew.html, flashback.html, sponsors.html. Includes original event dialogs, schedule tabs, guideline accordions, navigation, gallery and PDF downloads. Registration, sponsor booking, WhatsApp and social links retain their original external destinations.

Source repairs: corrected Flashback's broken sponsor.html links; use the existing original CodeYart PNG instead of its missing JPG. The original MRQ logo returns 404 and is hidden if unavailable.

The original hero video is optimized to 720p for hosting; all 60 Flashback gallery photos and both PDFs are included. Fonts, Tailwind CDN and embedded Google Maps require an internet connection.
